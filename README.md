# Cube Dog

箱を動的に生成してステージを攻略する3Dアクションパズルゲームです。
オブジェクトプールによるリソース管理、Gameplay Ability System（GAS）を用いたギミック制御、ImGuiによるインゲーム・デバッグ環境の構築など、商用開発を見据えた技術検証とC++でのシステム設計を目的として制作しました。



## 開発環境・プロジェクト概要
- **開発期間**: 2026年4月 〜 2026年5月（約1ヶ月）
- **ゲームエンジン**: Unreal Engine 5.5
- **言語 / フレームワーク**: C++ (メイン) / Blueprint / GAS / ImGui
- **プラットフォーム**: PC (Windows) / キーボード & コントローラー
- **ローカライズ**: 日本語 / 英語

## アーキテクチャ・設計方針

### 1. C++ と Blueprint の役割分担
中核となるゲームロジックはほぼすべて **C++** で実装し、アセット参照（SE、エフェクト、UIの処理等）やGASのデータ定義のみを **Blueprint（BP）** に委譲しています。

- **C++側**: 基本的なロジック全般
- **BP側**: ビジュアル、オーディオ、UIの処理、GASの処理

### 2. 協業を想定した疎結合設計（ハードコーディングの排除）
C++コード内でのアセット参照（SE・エフェクト・UIアニメーションのファイルパス等）のハードコーディングを徹底的に排除しました。

コアロジック側から `BlueprintImplementableEvent` を介して通知を送るのみに留め、具体的な演出の割り当てはBlueprint側に委譲しています。
これにより、プログラマーとデザイナーが衝突を起こさずに並行作業できる、実務のチーム開発を意識したアーキテクチャを維持しています。

## 技術的なアピールポイント（主要実装の深掘り）

### ◆ オブジェクトプールによる動的リソース管理（C++）
パズル要素のコアである「箱の生成」において、ランタイムでのメモリ確保・解放のオーバーヘッドを抑えるため、オブジェクトプールパターンを採用しました。
- **仕様の最適化**: 生成上限を10個に制限。上限を超えた際は最も古い箱を破棄。
- **UXの考慮**: 破棄される箱が事前にわかるよう、マテリアルパラメータを制御して発光するフィードバックを実装。
- **例外処理の排除**: プレイヤーが乗っている箱は破棄対象から除外。（発光する箱もリアルタイムで変化するように実装）

### ◆ GAS（Gameplay Ability System）を用いたギミック制御
センサー砲台、スイッチ連動の扉/回転/昇降足場などのステージギミックをGASで実装しました。
- **導入理由**: 中大規模開発で標準的に使われるフレームワークの習得、および機能拡張時の柔軟性を担保するため。
- **Gameplay Tagによる状態管理**: 各ギミックの「作動許可・不許可」などの状態を、複雑なフラグ（bool値）管理ではなく、アクターへのタグの付与によって簡潔に制御することを目指しました。

### ◆ ImGuiを統合したインゲーム・デバッグツール
開発・テスト効率の向上を目的として、ランタイムで各種パラメータの書き換えや状態の可視化ができるデバッグメニューを構築しました。

1. **オブジェクトプールの安全な一括クリーンアップ（箱を全部消す機能）**
   パズルの検証を一からやり直せるようにするためのリセット機能。
2. **ギミック単体テスト用の無敵化（プレイヤーを無敵にする機能）**
   マグマなどの即死トラップの影響を排除し、ギミックのみを集中してテスト可能に。
3. **デバッグ・イテレーションの高速化（チェックポイントへのワープ機能）**
   特定のチェックポイント周辺でテストを行う際、そこまで移動する手間の排除（開発効率の向上）。
   
### ◆ システム基盤（Subsystem & UI & 多言語化）
- **Subsystemの活用**: GameInstanceが神クラスにならないように `UGameInstanceSubsystem` を採用し、プレイヤーの座標保持やデバッグ機能を実現。
- **UI機能拡張**: 標準UserWidgetの機能を拡張し、キーボードとコントローラーの両方でフォーカス遷移を実装。操作ガイドのボタンアイコンも動的に切り替わるように。
- **ローカライズ**: テキストデータを外部CSVから動的に読み込むシステムを実装。ローカライゼーションダッシュボードを採用し、ゲーム内設定から日本語と英語を切り替え可能に。

## 操作方法（キーボード / XBoxコントローラー）
- **移動**: WASD / 左スティック
- **カメラ操作**: マウス / 右スティック
- **ジャンプ**: スペース / Aボタン
- **箱の生成**: マウス左クリック / Xボタン
- **向きの固定**: マウス右クリック / RBボタン
- **ポーズメニュー**: Pキー / Optionsボタン
- **デバッグメニュー表示**: Ctrl + Gキー
