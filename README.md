# Cube Dog

## プレイ動画
https://youtu.be/gknHRpCKOQQ

## 1. プロジェクト概要
本作は「箱を生成する能力」を駆使してステージを攻略する3Dパズルアクションゲームです。
UE5を使用して制作しました。

## 2. 開発環境
- **開発期間**: 2026年4月 〜 2026年5月（約1ヶ月）
- **言語**: C++
- **ゲームエンジン**: Unreal Engine 5.5
- **プラットフォーム**: Windows

## 3. 操作方法（キーボード / XBoxコントローラー）
- **移動**: WASD / 左スティック
- **カメラ操作**: マウス / 右スティック
- **ジャンプ**: スペース / Aボタン
- **箱の生成**: マウス左クリック / Xボタン
- **向きの固定**: マウス右クリック / RBボタン
- **ポーズメニュー**: Pキー / Optionsボタン
- **デバッグメニュー表示**: Ctrl + Gキー

## 4. 工夫した点
- 基本的にすべて C++ で実装し、アセット参照（SE、エフェクト、UIの処理等）やGASの処理のみ Blueprint に逃がしました。
- ゲームのコアシステムである「箱の生成」はオブジェクトプールによる設計をすることで処理が重くならないようにしました。
- 「箱の生成」は上限を超えたら古いものを破棄、その際に事前に分かるように光らせたり、プレイヤーが乗っている箱は消さないなどUXも意識しました。
- ギミックの実装にはGASを採用しました。本作の規模では不要かもしれませんが大規模開発を見据えた実装の学習を優先しました。
- 実務を想定して、ImGuiを使用したデバッグメニューの作成も行いました。
- Subsystemを活用してGameInstanceが神クラスにならないような設計を目指しました。
- UIはキーボードやコントローラーでも操作できるようにフォーカス遷移を実装、入力デバイスによってボタンアイコンが変化するなど遊びやすさを意識しました。
- テキストはcsvから読み込むようにしました。また、ローカライズも行い、英語にも対応するようにしました。

## 5. 今後の課題
- 規模が小さいため、大きくしたときに本当に破綻しない設計ができているかは不明瞭。実際に様々な機能を追加していきたい。
- プレイヤークラスが肥大化してきているため、GASを使ったりコンポーネントに切り分けたりを検討する余地がありそう。
- 箱はプールしているが、レティクルや敵の弾などは毎回スポーンしているので改善できそう。
